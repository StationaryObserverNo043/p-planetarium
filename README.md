# 🌌 パーソナリティ・プラネタリウム

### ― 星空に描く、あなたらしさ ―

> 自分の中にある星を、自分で観測する。

**パーソナリティ・プラネタリウム**は、
「好き・嫌い・得意・苦手」という4つの視点から、
自分自身を観測し、星空として眺めるためのデジタルアプリです。

## 🔭 Concept

人は、自分のことを意外と知らない。

好きなこと。
苦手なこと。
自然にできること。
なぜか避けてしまうこと。

それらを一つずつ観測していくと、
自分でも気づいていなかった「自分らしさ」が
少しずつ見えてくるかもしれません。

このアプリでは、日常のさまざまな活動や経験を入り口に、

- ⭐ **好き**
- 👾 **嫌い**
- 🪐 **得意**
- 🧬 **苦手**

という4つの視点から、自分について考えます。

そして、集めた情報を「星」として表現し、
自分だけの星空をつくっていきます。

## 🔭 What is this?

これは、性格を診断するためのアプリではありません。

「あなたは○○タイプです」と答えを決めるのではなく、

**自分自身を観測するための小さなプラネタリウム**

を目指しています。

星の意味を決めるのも、
星と星のつながりを見つけるのも、
最後に自分の物語をつくるのも、自分自身。

AIを活用する場合も、
答えを決める存在ではなく、
観測や整理をサポートする存在として扱います。

## ✨ Features

現在、以下のような体験を構想しています。

- 日常の活動や経験を選択・入力
- 「好き・嫌い・得意・苦手」の4つの視点から観測
- 自分の言葉で自由に入力
- 観測結果を星として可視化
- 星を集めて自分だけの星空を構成
- 星同士のつながりから「星座」を見つける
- 3D空間の星空を眺める
- 自分自身で星座に名前をつける

※アプリの詳細な仕様・UI・データ構造などは現在設計中です。

## 🪐 Philosophy

「好き」だけではなく、

「嫌い」も。

「得意」だけではなく、

「苦手」も。

どれも、自分を構成する大切な情報です。

このアプリでは、
苦手なことや嫌いなことを「欠点」として評価するのではなく、
**自分の中に存在する一つの星**として扱います。

> 自分の中に、こんな星があったんだ。

そんな小さな発見が生まれる場所を目指しています。
