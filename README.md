# 🌌 パーソナリティ・プラネタリウム

### ― 星空に描く、あなたらしさ ―

> 自分の中にある星を、自分で観測する。

**パーソナリティ・プラネタリウム**は、  
「好き・嫌い・得意・苦手」という4つの視点から、  
自分自身を観測し、星空として眺めるためのデジタルアプリです。

## 🔭 Concept

人は、自分のことを意外と知らない。

好きなこと。  
苦手なこと。  
自然にできること。  
なぜか避けてしまうこと。

それらを一つずつ観測していくと、  
自分でも気づいていなかった「自分らしさ」が  
少しずつ見えてくるかもしれません。

このアプリでは、日常のさまざまな活動や経験を入り口に、

- ⭐ **好き**
- 👾 **嫌い**
- 🪐 **得意**
- 🧬 **苦手**

という4つの視点から、自分について考えます。

そして、集めた情報を「星」として表現し、  
自分だけの星空をつくっていきます。

## 🔭 What is this?

これは、性格を診断するためのアプリではありません。

「あなたは○○タイプです」と答えを決めるのではなく、

**自分自身を観測するための小さなプラネタリウム**

を目指しています。

星の意味を決めるのも、  
星と星のつながりを見つけるのも、  
最後に自分の物語をつくるのも、自分自身。

AIを活用する場合も、  
答えを決める存在ではなく、  
観測や整理をサポートする存在として扱います。
